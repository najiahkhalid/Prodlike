# checkout-service

Prices a Kitaab.pk basket: book totals from catalogue-service plus the delivery fee.

## Commands

    npm test        run unit tests
    git diff        see your changes
    git log         recent commits in the release train
    git show <ref>  one commit in detail, e.g. git show HEAD
    logs <service>  tail production logs (checkout, catalogue, cache, db, gateway)
    rollback        roll production back to the previous release
