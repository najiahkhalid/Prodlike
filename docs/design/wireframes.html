WF-01 · PUBLIC

Home / Landing

Explain the idea in 5 seconds and get a visitor into a scenario with as few clicks as possible.

  1. Sticky top nav: logo (home), anchor links, Log in, primary Sign up.
  2. Hero: problem-led headline + 2–3 line value proposition.
  3. Primary CTA = guest demo (refinement: no sign-up needed). Secondary CTA scrolls to How It Works.
  4. Product visual: preview of the live system map during an incident, showing the "wow" feature.
  5. How it works: the 5-step lifecycle as a horizontal strip.
  6. Scenario library preview: 4 cards (difficulty, title, company, skills, time).
  7. Instructor section: benefits list + cohort stats preview.
  8. Closing CTA band (dark) repeats both actions.
  9. Footer: product, account and team links.
Navigation: Demo → Scenario Brief (guest) · Sign up/Log in → Auth page → Learner or Instructor dashboard · Card → Brief.

WF-02 · LEARNER

Scenario Catalogue

Help a learner pick the right next scenario quickly (FR-03).

  1. App sidebar (all logged-in pages): role-based links, current page highlighted, user at bottom.
  2. Page header: breadcrumb, title, keyword search.
  3. Filter chips for difficulty and skill; selected chip is filled, never colour alone.
  4. Card grid (3 columns → 2 → 1 on smaller screens). Whole card is clickable.
  5. Personal best shown on attempted scenarios.
  6. Assignment deadline flag from an instructor.
  7. Empty state with a recovery action (NFR-09).
Navigation: Card → Scenario Brief · Sidebar → Dashboard / Progress / Profile.

WF-03 · LEARNER / GUEST

Scenario Brief

Set the scene and make expectations explicit before the timer starts (FR-04).

  1. Guest banner, shown only in demo mode (refinement 1).
  2. Title + meta: difficulty, skills, estimated time.
  3. Ticket card written like a real issue tracker ticket.
  4. Story context: fictional company + teammate message (foreshadows the incident).
  5. Objectives & constraints, including permitted terminal commands.
  6. Transparent rubric: learners know how they are scored; hint penalty stated (refinement 3).
  7. Primary action: Start attempt. Sticky in the right column.
  8. Attempt history (hidden for guests).
Navigation: Start attempt → Scenario Workspace · Breadcrumb → Catalogue.

WF-04 · LEARNER · CORE PAGE

Scenario Workspace

An IDE + ops console in one screen. Simplified from 5 separate panels into 3 zones (refinement 4).

  1. Top bar: scenario identity; logo returns to dashboard (progress autosaved).
  2. Lifecycle stepper: shows where the learner is.
  3. Timer, Hint (−5) and the main action: Commit & Deploy (enabled only when tests pass).
  4. Zone 1a, file explorer: modified files marked “M”.
  5. Zone 1b, code editor with file tabs and line numbers.
  6. Run tests next to the code it affects.
  7. Zone 2, Terminal / Test results (tabbed), restricted commands.
  8. Zone 3, System (tabbed): Map, Pipeline, Incidents with an alert count.
  9. 3D / 2D toggle (refinement 2).
  10. Live metrics with sparklines.
  11. Incident actions: investigate, then recover.
Navigation: Deploy → modal (commit msg, strategy) → Pipeline tab → incident → Rollback/Hotfix → Finish attempt → Debrief.

WF-05 · LEARNER

Debrief & Score Report

Turn the attempt into learning: what you scored, why, and what to do next (FR-15).

  1. Header actions: Retry (improve score) and Next scenario.
  2. Score ring out of 100 + verdict and summary sentence.
  3. Badges earned (motivation / progression).
  4. Rubric bars with the reason for each score.
  5. Timeline of key decisions, marked good / risky / bad (FR-13).
  6. Senior-engineer notes: the main teaching moment.
  7. Recommendations targeting the weakest skill.
Navigation: Retry → Brief · Next → Catalogue/Brief · Guests see a “save this result: sign up” card.

WF-06 · INSTRUCTOR

Instructor Dashboard

Let a busy instructor run a lab without manual grading (FR-17, FR-18).

  1. Instructor sidebar: different menu for the role (FR-02).
  2. Primary actions: New cohort, Assign scenario (opens modals).
  3. Cohort switcher tabs: only the instructor's own cohorts (NFR-13).
  4. KPI tiles: enrolment, completion, average score.
  5. Join code to share with students.
  6. Assignments with deadlines and progress.
  7. Score distribution + most common mistake.
  8. Results table: drill down to any learner's debrief; struggling learners flagged.
  9. CSV export for the gradebook.
Navigation: Assign → modal (scenario, deadline, randomise faults) · Debrief link → learner's Debrief.
