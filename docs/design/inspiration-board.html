05 · Reference products we studied (what we took from each)

VS Code

Explorer / editor / terminal layout every developer knows.

Took: workspace zones, tabs, “M” modified marker, dark editor theme.

Grafana / Datadog

Ops dashboards with alerts, sparklines and severity.

Took: metric tiles with sparklines, SEV labels, red/amber/green state language.

Linear / Vercel

Modern developer-tool marketing pages.

Took: confident short headline, product visual in the hero, dark CTA band, generous white space.
✓ passed✕ failed● queued

GitHub Actions / Primer

CI pipeline stages and status iconography.

Took: stage-by-stage pipeline view, icon + label status badges.

LeetCode / Duolingo progress

Score feedback and streak-style motivation.

Took: score ring, badges, personal-best tracking (used sparingly to stay professional).

AWS / cloud architecture diagrams

Isometric service maps used in system-design talks.

Took: 2.5D node map for the live System Map, with a flat 2D fallback.

Thumbnails are simplified sketches drawn by the team to describe each reference; no third-party assets are used in the design.
